# Accepter les conditions d'utilisation — ce qui change pour toi

## Une case pour accepter les conditions d'utilisation

**Ce qui change** — Pour créer un compte, il faut cocher « J'accepte les conditions d'utilisation ». Sans la
case, l'écran refuse ; l'api refuse aussi, et note sur chaque nouveau compte l'instant où la case a été cochée.

**Pour qui** — Toute personne qui s'inscrit, sur le site comme dans l'app iPhone.

**Ce que tu vois maintenant** — La case au-dessus du bouton, avec le lien vers les conditions ; en dessous, la
phrase qui renvoie à la page « Données personnelles ».

**Ce qu'il faut faire différemment** — Rien.

**Depuis le** — pas encore : en attente de mise en ligne.
