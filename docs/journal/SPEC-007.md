# Une inscription plus sûre — ce qui change pour toi

## Une inscription plus sûre

**Ce qui change** — Pour créer un compte, on tape son mot de passe deux fois. Une jauge dit pendant la saisie
s'il est trop court, faible, moyen ou fort ; trop court ou faible, il est refusé. Une vérification anti-robot
se fait toute seule, sans rien à cocher.

**Pour qui** — Toute personne qui s'inscrit, sur le site comme dans l'app iPhone. Changer son mot de passe
refuse aussi désormais un mot de passe faible.

**Ce que tu vois maintenant** — Sous « Mot de passe », une jauge rouge, orange ou verte ; un champ « Confirmer
le mot de passe » ; la ligne « Vérifié : vous n'êtes pas un robot » au-dessus du bouton.

**Ce qu'il faut faire différemment** — Rien.

**Depuis le** — pas encore : en attente de mise en ligne.
